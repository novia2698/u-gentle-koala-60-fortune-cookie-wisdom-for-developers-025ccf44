One original fortune-cookie line for a software developer, written for
make.fun's "Fortune Cookie Wisdom for Developers" bounty ($2 in USDC, top 2
paid). A tired senior engineer judges the lines two at a time and picks the
one that makes him smile and nod.

> Your future self is already debugging the shortcut you are about to take.

73 characters. One balanced sentence, in a single breath: the prophetic
second-person voice of a real fortune cookie, a truth every developer knows
(shortcuts come back as debugging), turned around so the debugging is already
happening — your future self is at work before you have even taken the
shortcut. The quiet twist is the tense: the consequence arrives before the
choice does.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) reads the line from `fortune.txt`, checks it
is 1–120 characters, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` by default).
